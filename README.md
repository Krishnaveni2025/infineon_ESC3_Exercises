# Infineon Technologies ESC3 2025

This repository contains the resources, code, and documentation of the **Embedded Systems Course (Cohort 3)** at **Infineon Technologies**, Bangalore (Sept 13 - Dec 20, 2025).

## 📂 Repository Contents

This repository is organized into the following sections:

### 1. Assignments
Course assignments and practical exercises demonstrating mastery of specific peripherals and concepts.

### 2. Quizzes
Responses and explanations for course quizzes, covering theoretical aspects of the Cortex-M0+ architecture and PSoC 4 hardware.

### 3. Materials
Reference materials, datasheets, and lecture notes provided during the course for "Bare Metal" firmware development.
